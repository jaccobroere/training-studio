# DECISIONS.md — Sports Training Studio

Decisions locked during grilling (2026-09-29; decision 32 on 2026-10-11, see `SIMPLIFY.md`). The original handoff is input, not truth;
where this file disagrees with it, this file wins. Guiding rule: grugbrain — the fewest
moving parts that do the job well; modular and expandable, not clever.

Rows marked *Superseded* or *Partly superseded by 32* are kept for history; `SIMPLIFY.md` wins
where it disagrees. Rows 1, 7, 12, 13, 14, 18–20, 23–25, 27, 28 are unaffected (14 records the
spike on the earlier model).
