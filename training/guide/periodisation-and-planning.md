# Periodisation and planning in practice

How to draft and maintain multi-week training as dated workouts. Race-specific structure is in
`running-races.md`; load rules in `load-and-progression.md`.

Labels: **[E]** cited study · **[C]** coaching consensus · **[H]** heuristic.

## What periodisation evidence supports

- Classic models (linear, block, undulating) rest more on tradition than on head-to-head trials;
  individual responses vary, so plans should adapt to how training is actually absorbed.
  [E Kiely 2018]
- Block periodisation (concentrated 2–4 week emphases) is an option for advanced athletes with
  many abilities to maintain; evidence is mostly in trained athletes. [E Issurin 2010]
- Practical stance: a clear direction (what the phase is for) + flexible weeks. [H]

## Planning horizon [H]

- **Weeks 1–3/4: detailed.** Dated workouts with items (distance/time, intensity, sets×reps).
- **Later weeks: guidance.** Phase name, target weekly volume range, long-run range, key-session
  type, cutback weeks marked. Fill them in 1–2 weeks ahead with real data.
- Race week and taper can be sketched early (they rarely change) but keep them editable.
- Re-check the plan every 1–2 weeks: actual volume, longest run, missed sessions, how the user feels.

## Building a week around fixed commitments

1. Ask/collect recurring commitments (sport, day, time, duration, typical intensity) and
   unavailable days. Treat them as fixed unless the user says otherwise.
2. Rate each commitment's leg cost: easy / moderate / hard (see `other-sports.md`).
3. Place anchors: long run, then quality sessions, then strength, then easy runs
   (spacing rules in `running-races.md`).
4. Count hard leg days across all sports; ~3/wk default (`load-and-progression.md`). If over,
   say which session to soften or swap and what that trades.
5. Watch the week boundary: Sunday long run + Monday hard class are consecutive hard days even
   though weekly totals reset.
6. Leave at least one full rest or very easy day per week for most amateurs. [H]

## Priority labels [H]

- **A** = protected when feasible (long run, key quality, race). **B** = valuable but replaceable.
  **C** = optional (extra easy run, accessories, second skate).
- Priority is protection, not obligation: pain, illness and real fatigue override it.
- Optional means optional: missed C sessions are not a backlog.

## Missed sessions and replanning [H]

- One missed easy run: let it go. Don't add its distance elsewhere.
- Missed quality session: do it within 1–2 days only if the spacing to the next hard day/long run
  survives; otherwise skip it.
- Missed long run: move it ≤2 days if the week allows; never stack it the day before/after
  another hard day; otherwise run next week's long run at the *last completed* length.
- Missed week (busy, minor illness): repeat the last completed week, then continue.
- ≥2 weeks missed: follow the restart table in `load-and-progression.md`; shorten the plan by
  cutting base/build, never the taper (`running-races.md`).
- If the race goal no longer fits, say so early and offer options (finish goal, later race,
  shorter distance).

## When tired or short on time, cut in this order [H]

1. Optional accessories and C sessions. 2. Optional extra sport sessions. 3. Secondary strength
work. 4. Quality volume (fewer/shorter reps, same pace). 5. Total running volume. The long run
rises in priority in the specific phase but pain, illness or real fatigue can still cancel it.

## Substitutions [H]

Match the purpose and say what the swap doesn't preserve:

| Intended | Reasonable swap | Doesn't preserve |
|---|---|---|
| Quality run | hard ride, hard skate, hard row | running-specific pace, economy |
| Easy run | easy ride, easy skate, swim, elliptical | impact tolerance, foot/calf conditioning |
| Long run | shorten or move; split only as last resort | running-specific endurance (nothing equivalent) |
| Gym lower session | home split squats, calf raises, jumps | heavy loading if equipment differs |
| Planned rest | — | don't swap rest for "light" extra work by default |

Cross-training never exceeds the gains of sport-specific training; swimming transfers least to
running fitness. [E Tanaka 1994]

## Planned vs actual

- The plan is a hypothesis; completed training is the data. Next weeks build on what was done,
  not on what was planned. [H]
- Compare actual vs planned weekly volume, longest run, and hard-day count; a cutback or stable
  week can be a success. Progress has several dimensions: volume, durability, pace at a given
  effort, strength, consistency. [H]
- Don't "fix" an under-volume week by overloading the next.
- When the user deviates, ask whether it was intended (life, preference) before treating it as a
  problem.
