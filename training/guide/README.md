# Coaching guide (index)

Read a file with `read_guide(topic)` before drafting training or answering method questions.

| Topic | Read it when |
|---|---|
| `running-races` | Drafting or reshaping a 5K/10K, half or marathon block: length, phases, entry base, key sessions, week layout around commitments, short blocks |
| `load-and-progression` | Setting weekly volume, cutbacks, the 10% rule/ACWR, restarting after a break, counting load across sports |
| `intensity` | Easy vs hard balance, zones (RPE, talk test, HR, pace), threshold, writing intensity into workout items |
| `long-runs-and-taper` | Long-run caps and progression, marathon-pace work, race fuelling and hydration, taper length and volume |
| `strength` | Strength for endurance athletes or in general: dosing, RIR, plyometrics, maintenance, placement, writing sets/reps |
| `periodisation-and-planning` | Planning several weeks, recurring commitments, priorities, missed sessions, substitutions, planned vs actual |
| `recovery-beginners-safety` | Sleep/HRV/RHR limits, illness and pain rules, red flags, energy availability, beginners, older athletes |
| `other-sports` | Skating, cycling, swimming, climbing/fingers, mobility/handstands, team sports: leg cost and scheduling |

Citing: say "coaching guide: <topic>" and keep the label: **[E]** cited study, **[C]** coaching
consensus (named plans/books), **[H]** heuristic. The guide is general evidence and practice; the
user's Profile/principles are their own choices. Say which is which, and let the user decide.
